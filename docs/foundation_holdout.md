## Постановка

Проверяем официальный курс Банка России на 1–7 календарных дней вперёд. Срез для каждого прогноза сделан в 00:00 МСК. Тест состоит из 680 дат с 01.01.2025 по 11.11.2026. Даты, фактические значения и прогнозы текущего ансамбля взяты из того же файла, что и в [анализе корреляций](correlation_holdout.md).

Каждой модели подаётся окно из 256 дневных значений курса, включая курс, действующий на дату прогноза. Во втором прогоне добавляются биржевой спред CNY/RUB к курсу ЦБ, базис синтетического USD/RUB через юань, дневное изменение расчётной цены Si и календарь фиксации курса. Синтетический курс берётся из исследовательской панели. Если точное время публикации USD/CNY неизвестно, в ней используется 10-дневный лаг. Рыночные признаки заканчиваются на дате прогноза. По будущим датам модели получают только календарь, известный на момент среза. EXAONE Finance проверяется по одному ряду в соответствии с режимом опубликованного чекпойнта. [Конфигурация лагов](../config/ml_holdout.json)

Берём медиану прогноза. Для обеих постановок применяем ту же календарную обработку, что и для ансамбля. Пока новый фиксинг не вступил в силу, сохраняется текущий курс. Прогнозы для дат действия одного фиксинга усредняются.

RMSE считается в рублях по каждому горизонту. Главная метрика — среднее отношение этих семи RMSE к ошибкам случайного блуждания. Для горизонта в один день отдельно проверены 459 дат с новым фиксингом. Интервалы разницы с ансамблем рассчитаны по 2 000 парным выборкам блоков по 28 дней. Интервалы относятся к уже использовавшемуся историческому тесту. Точное пересечение USD/RUB с корпусами предобучения не установлено.

## Запуск на MacBook Air M4

Файлы прогонов и версии весов лежат в `data/reports/foundation_holdout`. `summary.csv` содержит сводку, `metrics.csv` — значения по горизонтам и условные ошибки после первого нового фиксинга, `<model>.csv.gz` — прогнозы до и после календарной обработки. В `<model>.json` записаны источник весов, ревизия, устройство, размер пакета и пиковая RSS процесса. RSS не включает отдельные выделения памяти GPU. Время считается после загрузки модели и включает первый пакет и проверку независимости пакетного прогноза.

Запуск выполнялся из каталога проекта с Python 3.12, PyTorch 2.15.0 и MLX 0.32.4. Адаптеры используют следующие пакеты и чекпойнты.

| Ключ | Пакет | Чекпойнт |
| --- | --- | --- |
| `timestral_28m` | Timestral 1.0.0, код Mistral | [mistralai/Timestral-28M](https://huggingface.co/mistralai/Timestral-28M) |
| `tirex_2` | `tirex-2==0.5.0` | [NX-AI/TiRex-2](https://huggingface.co/NX-AI/TiRex-2) |
| `chronos_2` | `chronos-forecasting==2.3.2` | [amazon/chronos-2](https://huggingface.co/amazon/chronos-2) |
| `t0_gamma` | `tfc-t0[mlx]==0.6.1` | [theforecastingcompany/t0-gamma](https://huggingface.co/theforecastingcompany/t0-gamma) |
| `ci_proto` | `continuousintelligence==0.2.0` | [ContinuousIntelligence/ci-proto](https://huggingface.co/ContinuousIntelligence/ci-proto) |
| `timesfm_3` | `timesfm[torch]==3.0.2` | [google/timesfm-3.0-pytorch](https://huggingface.co/google/timesfm-3.0-pytorch) |
| `exaone_finance` | EXAONE Forecast 1.0.0, код LG AI Research | [LG-AI-Research/EXAONE-Forecast-for-Finance-1.0](https://huggingface.co/LG-AI-Research/EXAONE-Forecast-for-Finance-1.0) |

Для воспроизведения файлы чекпойнта нужно положить в `data/model_runtime/checkpoints/<model>` и скопировать туда метаданные из `data/reports/foundation_holdout/<model>.json` под именем `checkpoint.json`. Часть весов удалена после прогонов, чтобы освободить диск. Их можно заново скачать по записанной ревизии и сверить контрольную сумму. Для ci-proto нужен `tta.json` из той же ревизии. У EXAONE имя `model.safetensors` в папке чекпойнта — ссылка на `exaone-finance-1.0.safetensors`.

Timestral запускали на CPU из-за нормализации в FP64. Для ci-proto отключили настройки, которые объединяют независимые окна в одну задачу. Историческая нормализация осталась на CPU. На GPU вычислили ту же рекуррентную формулу Mamba-3 двумя пакетными матричными умножениями в FP32. На двух датах и семи горизонтах максимальное расхождение медиан с исходной реализацией на CPU составило 0,000008 ₽ в обоих режимах. [Код модели Continuous Intelligence](https://github.com/continuousintelligence/ci), [адаптер](../scripts/ci_mamba_inference.py)

Пример запуска после установки зависимостей и загрузки весов.

```bash
python scripts/foundation_holdout.py --model t0_gamma --device mlx --batch-size 16
python scripts/foundation_holdout.py --model summary
```
