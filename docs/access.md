# Доступ и ключи

Для основной выгрузки ключи и аккаунты не нужны. Платные подписки не используются.

## ALFRED: необязательный бесплатный FRED API key

Обычные ряды FRED скачиваются через публичный CSV. Ключ нужен для отдельной команды `alfred`, которая получает версию ряда на выбранную историческую дату.

1. Создать аккаунт на [FRED](https://fredaccount.stlouisfed.org/).
2. Открыть [API Keys](https://fredaccount.stlouisfed.org/apikeys), выбрать создание ключа и описать исследовательский проект.
3. Установить ключ в переменную окружения `FRED_API_KEY` в терминале, из которого запускается проект. В zsh можно ввести его без отображения:

```sh
read -rs 'FRED_API_KEY?FRED API key: '
export FRED_API_KEY
uv run usd-rub alfred --series usd_cny --vintage 2020-03-20 --start 2015-01-01 --end 2020-03-20
```

Ключ не требуется передавать в чат или сохранять в репозитории. Загрузчик исключает его из сохраняемого URL. Требования к ключу описаны в [официальной документации FRED](https://fred.stlouisfed.org/docs/api/api_key.html).

Один винтаж — один снимок. Для исторической проверки нужны снимки на соответствующие даты прогноза; один сегодняшний CSV их не заменяет. Время доступности снимка консервативно задаётся концом дня винтажа в часовом поясе Chicago. Это не точное время внутридневного релиза.

## Росстат и Минфин

Платного ключа для исторических XLS/XLSX не требуется. Росстат возвращал 403 при системном HTTPS-клиенте; Python также получил ошибку проверки цепочки сертификатов. Для macOS реализован резервный режим `fetch --browser-fallback`: публичный запрос выполняется через Chrome, без передачи авторизационных cookies. Нужны установленный Chrome и разрешённое выполнение JavaScript из Apple Events. Если вкладки источника нет, загрузчик временно открывает её и затем закрывает. Исходный файл попадает в обычный raw-архив с отметкой транспорта. Проверка TLS не отключается.

Так получен реальный ИПЦ за 2015–2026. Минфин после первоначального 503 стал доступен обычному HTTP-клиенту; парсер нашёл страницу месячного бюджета, перешёл к XLSX и получил историю нефтегазовых доходов. При ошибке Минфина тот же резервный режим доступен и для его публичных файлов.

Таблицу также можно скачать через браузер и обработать командой `import-table`. Инструкция — в [imports.md](imports.md). Две проверенные ссылки на розничный оборот возвращают 404 и через Chrome; этот ряд пока не собран.

## MOEX

Публичный ISS не требует токена. Некоторые поля в исторической выгрузке доступны, другие скрыты. В проверенном CNYRUB_TOM поле `volume` свечей равно `null`, а в дневной истории столбцов объёма нет. Код не запрашивает платную подписку и не заменяет пропуск нулём. Подход с бесплатными задержанными и подписными данными описан [биржей](https://www.moex.com/a8531).
