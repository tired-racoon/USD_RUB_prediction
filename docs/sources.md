## Что пока не получено

| Пункт списка | Результат проверки / ограничение |
|---|---|
| OTC USD/EUR/CNY turnover | SOAP VKO заканчивается 11.07.2024. Отключён; действующий числовой ряд 2026 не получен |
| Сальдо операций ЦБ | Старый SaldoXML заканчивается 30.12.2025. Отключён |
| Старые интервенции ЦБ | Выгрузка неполна. Единица исправлена на млн USD, ряд исключён. Не заменяет бюджетные операции Минфина |
| GDELT | Отключён по требованию пользователя, в новые признаки не входит |
| CNYRUB_TOM volume | В проверенных бесплатных свечах MOEX `volume=null`; число сделок доступно отдельно |
| Розничный оборот | Обе опубликованные ссылки Росстата возвращают 404, включая загрузку через Chrome |
| Дневной Urals, freight, AIS, полные crude/LNG flows | Платные Argus/Kpler/Vortexa/Clarksons исключены. Бесплатная полноценная замена не собрана |
| ENTSOG, импортная статистика Eurostat | Получены пробные JSON-ответы; полноценные исторические ряды потоков не нормализованы. Не учитываются как готовые данные |
| CNH, CNH–CNY basis | Проверенный запрос ECB вернул 404; CNY не подставляется вместо CNH |
| PBoC fixing surprise, ожидаемая ставка/CBR surprise | Требуются отдельная история fixing/консенсуса и методика ожиданий; готовые ряды не получены |
| Опционные IV/skew/risk reversal по другим валютам, CNY swap curve, OFZ-IN breakeven | Сопоставимые ряды в текущем датасете отсутствуют |
| Наличные/банковские котировки, bid/ask/dispersion | Подтверждённого бесплатного архива за десять лет нет; текущие котировки не восстанавливают прошлое |
| GDP/nowcast, промпроизводство Китая | Эти отдельные ряды не собраны. PMI не подменяет их |
| Аукционы/погашения/купоны ОФЗ, settlement calendar MOEX | Полная историческая таблица не получена; проверенный settlement URL вернул 404. Рыночные метаданные ISS не считаются календарём |
| US/China holidays и расчётные сезонные признаки | Полные официальные исторические календари не собраны. Номинальные признаки месяца/дня доступны в `features` |
| Ликвидная часть ФНБ, фактические дневные зеркальные операции | Получены общий ФНБ и месячные объявления; отдельные указанные ряды не восстановлены |
| Обязательная продажа/репатриация, ограничения переводов, price cap и страхование | Нужен исторический реестр норм с датами публикации и действия. Страница pravo.gov.ru завершилась ошибкой TLS; страницы government/Kremlin сохранены только как проверка доступа. Готовая история норм не создана |
| Санкционные связи банков/экспортёров/судов, payment corridors, военные/дипломатические события, sentiment | Есть исходные официальные тексты и текущие списки. Классификаторы, граф связей и количественные индексы не обучены; это следующий этап исследования |
| Незавершённые расчёты, будущие продажи валюты/налоговая потребность, receipts lag | Не наблюдаются как готовые ряды. «Прочая задолженность» ПБ сохранена под собственным названием и не названа незавершёнными расчётами |
| DXY ICE, терминальные/real-time данные | Платные источники исключены; открытый широкий доллар Fed хранится под своим названием |
| Zenodo из DOCX | Отключён: происхождение и смысл ряда ключевой ставки не подтверждены. Набор не используется в обучении |

Расчётные cross, спреды ставок и календарные признаки реализованы в `features`; futures basis, налоговые оценки и латентные величины требуют отдельной методологии. Базовые прогнозы описаны в [models.md](models.md).
