# Предобученные прогнозы в ансамбле USD/RUB

Смесь с 15% t0-gamma на 4–7 днях служит базой основного прогноза. На 1–3 днях до календарной обработки база равна классической смеси. Текущий прогноз добавляет к базе рыночную поправку XGBoost. Ниже результаты сравнения смесей с t0-gamma и другими предобученными моделями. [Поправка XGBoost](theory_holdout.md) · [Запуск прогноза](setup.md#основной-прогноз-usdrub)

## Результаты

Выбранный по 2021–2024 годам гибрид добавляет 25% TimesFM 3.0 на горизонтах 4–7 дней. В калибровке он снижает среднюю ошибку с 90,44% до 90,10% от случайного блуждания. На тесте 2025–2026 годов она выросла с 91,02% до 91,26%. Парный 95%-й интервал изменения от −0,68 до +1,00 п.п. включает ноль.

| Вариант | RMSE к случайному блужданию, калибровка | RMSE к случайному блужданию, тест | RMSE на 7 дней, ₽ |
| --- | ---: | ---: | ---: |
| Классический ансамбль с календарём | 90,44% | 91,02% | 1,675 |
| 25% TimesFM 3.0 на 4–7 днях, выбран по калибровке | **90,10%** | 91,26% | 1,682 |
| 15% t0-gamma на 4–7 днях | 90,38% | **90,95%** | 1,671 |
| 15% Timestral-28M на 4–7 днях | 90,33% | 91,01% | 1,673 |
| 10% Chronos-2 на 4–7 днях | 90,40% | 91,01% | 1,673 |
| Совместный подбор общих весов | 90,38% | 91,32% | 1,676 |
| Фиксированные 10% на среднее семи сетей | 90,62% | 91,32% | 1,673 |

Для t0-gamma калибровка выбрала 15% на 4–7 днях и ноль на 1–3 днях. Этот вариант оказался точнее остальных на тесте по средней ошибке, с выигрышем 0,07 п.п. к классическому ансамблю. Парный интервал изменения от −0,38 до +0,16 п.п. включает ноль. При совместном подборе TimesFM 3.0 получил 8,61% общего веса, классический ансамбль получил остальные 91,39%. По отдельности с общим весом ненулевой вклад получила только TimesFM 3.0, а случайное блуждание получило нулевой вес и в контроле, и в общей смеси.

На седьмой день смесь с t0-gamma снизила RMSE с 1,6752 до 1,6706 ₽. Выигрыш составляет 0,0046 ₽ (0,28%). Парный 95%-й интервал выигрыша по 2 000 выборкам 28-дневных блоков составляет от −0,0029 до +0,0126 ₽.

При фиксированном добавлении 10% на всех горизонтах каждый из семи предобученных прогнозов повысил средний RMSE на тесте. Из этих смесей наименьшую ошибку дал t0-gamma с рынком и календарём, 91,20% от случайного блуждания.

В дополнительной пробе по уже просмотренному тесту 10% t0-gamma на горизонтах 4–7 дней дали 90,96%. Семидневный RMSE снизился с 1,675 до 1,672 ₽. Парный 95%-й блочный интервал изменения средней ошибки от −0,28 до +0,09 п.п. включает ноль. Этот расчёт сделан отдельно от подбора весов по 2021–2024 годам.

## Постановка

За основу взята классическая смесь Ridge, HistGradientBoosting и Extra Trees. Их внутренние доли равны 43,84%, 38,44% и 17,72%. К её прогнозу добавляются медианные прогнозы предобученных моделей. Календарная обработка применяется после смешивания к каждому варианту, включая исходный ансамбль.

Веса и набор входов выбраны на 1 433 вневыборочных датах 2021–2024 годов. Для классических компонентов параметры фиксированы, модели для каждого годового блока обучены на более ранних данных. Критерий подбора — среднее по годам отношение RMSE к случайному блужданию, усреднённое по семи горизонтам. Для проверки использованы те же 680 дат с 01.01.2025 по 11.11.2026. Чекпойнты и режимы входов совпадают с [проверкой самостоятельных прогнозов](foundation_holdout.md).

Проверены добавление одной модели с общей долей, отдельно подобранные доли на горизонтах 1–3 и 4–7 дней, совместное взвешивание всех нейросетевых прогнозов и такое же взвешивание со случайным блужданием. Добавление одного случайного блуждания к ансамблю служит контролем, который проверяет, объясняется ли возможный выигрыш простым приближением к текущему курсу. Для одной модели доля выбиралась из 0%, 5%, 10%, 15%, 25%, 40% и 60%. Для совместных прогнозов использован подбор неотрицательных весов с суммой один и квадратичным штрафом на доли добавленных прогнозов. Сравнение режимов и веса зафиксированы по 2021–2024 годам. Дополнительно проверена смесь с фиксированной долей 10% на среднее семи нейросетевых прогнозов. Для этой смеси брались прогнозы с рынком и календарём, а для EXAONE Finance — прогноз по истории курса.

Архив классического ансамбля использует общие настройки, выбранные до 2025 года. Блоки 2021–2024 служат калибровкой весов. Возможное пересечение истории USD/RUB с корпусами предобучения чекпойнтов остаётся неизвестным.

## Воспроизведение

Для каждой модели нужно пересчитать прогнозы на 2021–2024 годах с тем же чекпойнтом, что и в тестовом архиве. Пример для Timestral.

```bash
python scripts/foundation_holdout.py --model timestral_28m --device cpu \
  --oof data/reports/llm_news_holdout/baseline_oof.csv.gz \
  --output data/reports/foundation_ensemble/calibration
python scripts/foundation_ensemble.py
```

В `data/reports/foundation_ensemble/` сохраняются выбранные веса, метрики по горизонтам, прогнозы на тесте и контрольные суммы входов. Интервалы разницы с ансамблем посчитаны по 2 000 парным выборкам блоков длиной 28 дней.
