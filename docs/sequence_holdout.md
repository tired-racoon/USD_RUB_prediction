# Нейросети и отбор признаков в прогнозе USD/RUB

Проверены LSTM, GRU, CNN и Transformer. Каждая сеть одновременно прогнозирует семь поправок к случайному блужданию на горизонтах 1–7 дней. Входы включают историю за 16 суток со срезом в 00:00 МСК на дату прогноза. Ширина представления — 24. Сравнивались 4, 8 и 16 эпох. Ridge на текущем срезе обучен для сравнения без временного окна.

Во всех прогонах использован [общий снимок](../datasets/usd_rub_2011_2026_full.csv.gz). На каждом фолде признаки должны быть заполнены хотя бы на 50% всей доступной истории и последних четырёх лет. Средние, масштабы и ранжирование рассчитаны на обучающих данных. Цели для обучения заканчиваются до начала фолда. Важность признака — среднеквадратичный коэффициент регуляризованной Ridge-регрессии по семи стандартизованным доходностям. Это мера полезности для линейной модели. Для финального обучения допущены 519 признаков, для сокращённой панели взяты 64 с наибольшей оценкой.

Выбор эпохи, коэффициента усадки и весов ансамбля сделан на четырёх годовых фолдах с 2021 по 2024. Тест — 680 дат прогноза с 01.01.2025 по 11.11.2026. Для каждого горизонта RMSE делится на RMSE случайного блуждания, затем берётся среднее. Меньшее значение лучше.

| Модель | RMSE к RW, полный набор | RMSE к RW, 64 признака |
| --- | ---: | ---: |
| LSTM | 101,57% | 98,52% |
| GRU | 102,31% | 97,63% |
| CNN | 102,42% | 98,23% |
| Transformer | 103,14% | 98,17% |
| Ridge | 99,47% | 98,07% |

Валидация выбрала четыре эпохи для всех архитектур. Лучшей одиночной нейросетью на валидации была LSTM на 64 признаках. На тесте минимальная ошибка среди нейросетей была у GRU на 64 признаках. Новый ансамбль получил 97,49%, прежний — 91,96%.

Прогнозы всех восьми вариантов нейросетей повторно использованы в [ансамблях с Ridge и классическими моделями](forecast_stacking.md).

## Древесные модели

У CatBoost, Extra Trees и HistGradientBoosting проверены панели по 32 и 64 признака с тем же отбором внутри каждого фолда. Размер панели выбрали на валидации. Гиперпараметры, окно обучения и усадка взяты из парного [эксперимента с Минфином и Росстатом](minfin_rosstat_holdout.md). Для всех трёх моделей валидация выбрала 32 признака.

| Модель | RMSE к RW, полный набор | RMSE к RW, 32 признака | RMSE на день, ₽ | RMSE на 7 дней, ₽ |
| --- | ---: | ---: | ---: | ---: |
| HistGradientBoosting | 92,71% | 92,19% | 0,491 | 1,673 |
| CatBoost | 95,33% | 94,99% | 0,515 | 1,705 |
| Extra Trees | 95,56% | 95,97% | 0,525 | 1,707 |
| Прежний ансамбль | 91,96% | | 0,480 | 1,678 |

Компактный HistGradientBoosting снизил нормированный RMSE на 0,52 п.п. относительно того же бустинга на полном наборе. По среднему за семь горизонтов лучший результат у прежнего ансамбля. На семь дней разница в пользу компактного бустинга составила 0,005 ₽. Парный 95%-й интервал от −0,050 до +0,068 ₽ пересекает ноль. Интервал рассчитан по 2 500 бутстрэп-выборкам с блоками по 28 дней.

## Воспроизведение

```bash
uv run --extra sequence python scripts/sequence_holdout.py
uv run --extra sequence --extra ml python scripts/compact_tree_holdout.py
```

Отчёты сохраняются в `data/reports/sequence_holdout`. В `features_ranked.csv` сохранено ранжирование до каждого фолда. Снимки `dataset_top32.csv.gz` и `dataset_top64.csv.gz` используют финальный список признаков, выбранный на данных до 2025 года. Чтобы повторить валидацию 2021–2024, запускайте скрипты на общем снимке с отбором внутри каждого фолда.
