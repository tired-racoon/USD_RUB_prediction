# Ансамбли на архиве прогнозов USD/RUB

## Результаты

Ridge поверх прогнозов прежних нейросетей и классики дал 90,66% от RMSE случайного блуждания на 680 тестовых датах. Текущий ансамбль даёт 91,02%. Если перенастроить только классические прогнозы, получается 90,75%. Вклад LSTM, GRU, CNN и Transformer сверх такой перенастройки составил 0,09 п.п. с парным 95%-м интервалом от −0,004 до +0,174 п.п. Положительное число означает снижение ошибки.

| Вариант | RMSE к случайному блужданию | RMSE 1 день, ₽ | RMSE 7 дней, ₽ |
| --- | ---: | ---: | ---: |
| Классический ансамбль | 91,02% | 0,457 | 1,675 |
| Ridge только на классических прогнозах | 90,75% | 0,451 | 1,676 |
| Ridge на классике и LSTM, GRU, CNN, Transformer | 90,66% | 0,449 | 1,676 |
| Ridge на классике и предобученных моделях, выбор по валидации | 90,74% | 0,446 | 1,702 |
| Ridge на всех моделях | 90,58% | 0,448 | 1,677 |
| Неотрицательная смесь классики и LSTM, GRU, CNN, Transformer | 91,00% | 0,457 | 1,676 |
| Неотрицательная смесь всех моделей | 91,30% | 0,463 | 1,676 |
| Усиление поправки классического ансамбля к текущему курсу | 90,53% | 0,445 | 1,681 |
| Ridge на всех моделях с добавлением случайного блуждания | **90,37%** | 0,444 | 1,682 |

Среди отдельных архитектур наименьшую тестовую ошибку дал Ridge с CNN и классикой, 90,55%. У варианта с Transformer получилось 90,57%, у LSTM и GRU по 90,85%. Эти результаты относятся к общему историческому тесту. Лучшей по расширяющейся валидации среди исходных спецификаций была смесь классики и предобученных моделей, 92,05% против 92,62% у действующего ансамбля.

На однодневном горизонте Ridge присваивает ряду нейросетевых прогнозов отрицательные коэффициенты. В отдельном контроле Ridge обучался только менять масштаб поправки классического ансамбля к текущему курсу. Коэффициент масштаба составил 1,33 на один день и 1,13 на семь дней. При добавлении случайного блуждания в оба сравниваемых стека дополнительный выигрыш старых нейросетей составил 0,007 п.п. с интервалом от −0,115 до +0,184 п.п. Полный стек со случайным блужданием выиграл у простого масштабирования 0,16 п.п. с интервалом от −0,19 до +0,53 п.п. Основной выигрыш относительно прежнего ансамбля сосредоточен на горизонтах 1–3 дня.

## Как считалось

В общий архив вошли 28 рядов прогнозов. Это действующий классический ансамбль, случайное блуждание, пять отдельных классических прогнозов, восемь вариантов LSTM, GRU, CNN и Transformer и 13 вариантов предобученных моделей. Пять классических прогнозов включают три компонента действующего ансамбля и два Ridge из [эксперимента с нейросетями](sequence_holdout.md). Для четырёх архитектур включены обе прежние панели, полная и top64.

Тестовые прогнозы взяты из существующих архивов. Для 1 433 дат 2021–2024 годов восстановлены прогнозы отдельных классических компонентов и моделей из прежнего эксперимента. Каждый годовой блок считался по данным до его начала. Эпохи, отбор признаков и усадка соответствуют прежним настройкам. Повторный расчёт совпал с опубликованными метриками валидации нейросетей, а пересчитанные классические компоненты воспроизвели архив ансамбля. Прогнозы предобученных моделей взяты из [предыдущего эксперимента](foundation_ensemble.md).

Ridge обучается отдельно на каждом горизонте и прогнозирует поправку к классическому ансамблю. Его входы — разности между прогнозом каждого компонента и классическим ансамблем. Коэффициенты могут иметь любой знак. Для сравнения обучена выпуклая смесь с одними весами для горизонтов 1–7 дней. Её веса неотрицательны и в сумме дают один.

Подбор регуляризации и сравнение агрегаций сделаны на расширяющейся валидации 2022–2024 годов. Первый фолд обучается на прогнозах 2021 года. Перед каждым разделением проверяется доступность целей всех семи горизонтов. Итоговые веса обучены на всех данных 2021–2024 годов и применены к 680 тестовым датам 2025–2026. После смешивания используется один и тот же календарь фиксинга ЦБ. Парные 95%-е интервалы рассчитаны по 2 000 выборкам блоков длиной 28 дней.

Контроли со случайным блужданием добавлены после просмотра коэффициентов. Их веса обучены по той же исторической схеме. Варианты контроля показаны отдельно от исходного выбора по валидации.

Параметры базовых моделей уже подбирались на части дат до 2025 года. Валидация нового стека служит для выбора агрегации. Итоговое сравнение использует прежний исторический тест.

## Воспроизведение

```bash
uv run --extra sequence python scripts/prepare_stack_forecasts.py sequence
uv run --extra ml python scripts/prepare_stack_forecasts.py classical
uv run --extra ml python scripts/forecast_stacking.py prepare
uv run --extra ml python scripts/forecast_stacking.py fit
```

Последняя команда работает только с сохранёнными архивами. В `data/reports/forecast_stacking` находятся `calibration_forecasts.csv.gz`, `test_forecasts.csv.gz`, `coefficients.csv`, `summary.csv`, `metrics.csv`, `paired_comparisons.csv` и прогнозы смесей. В `archives.json` зафиксированы контрольные суммы источников и собранных архивов.
