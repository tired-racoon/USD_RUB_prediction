# Сравнение DFM Giannone с эталонными моделями

Расчёт завершён 18.11.2026. На полной проверке дневная адаптация Giannone, Reichlin, Small (2008) **не превзошла случайное блуждание** по RMSE и MAPE на горизонтах 1 и 7 дней. На семи днях обе версии DFM лучше AR(1) уровней. Это результат фиксированной спецификации, а не утверждение о любой факторной модели.

Изученная статья — `info/giannone2008.pdf`; дополнительно проверено техническое приложение A.2–A.3. Описание алгоритма, соответствие уравнениям и изменения для валютного курса — в [giannone_method.md](giannone_method.md).

## Условия сравнения

Цель — официальный USD/RUB ЦБ, 4340 календарных значений с 01.01.2015 по 18.11.2026. Для всех девяти строк сравнения используются одинаковые 3602 даты прогноза с 01.01.2017 по 11.11.2026 и горизонты 1–7 календарных дней. Обучающее окно 730 дней, переоценка каждый день. Два фактора и два общих шока, как в статье; параметры не подбирались по тестовому периоду. Всего сохранено 226 926 прогнозов.

Семь прежних бейзлайнов пересчитаны заново, их прогнозы полностью совпали с предыдущим запуском с процентными метриками. Новые строки — `dfm_giannone_strict` и `dfm_giannone_assumed`.

Номинальное покрытие интервалов — 95%. Для DFM фактическое покрытие около 95,3–95,5% на одном дне и 94,1–94,2% на семи днях. Это условные нормальные интервалы с фиксированными оценёнными параметрами; дополнительная калибровка и усадка дисперсии не применялись.

Основные метрики включают дни без изменения курса. MAPE при изменении использует только случаи, когда S[t+h] отличается от S[t]; таких случаев 2427 на одном дне и 3559 на семи днях. Процентные ошибки считаются от фактического уровня курса, не от его дневного изменения.

В CSV сохранён тест Diebold–Mariano относительно RW на квадратичных потерях. На семи днях p-value составляет 0,0029 для `strict` и 0,0064 для `assumed`, направление различия — в пользу RW. Используется HAC по перекрытию горизонтов, без поправок на множественные сравнения; эти p-value не являются гарантией устойчивости результата вне выборки.

## Доступность и диагностика

В режиме `strict` во всех обучающих окнах использовались семь рядов: официальные CNY/RUB и EUR/RUB, CNYRUB_TOM, ближайший Si, IMOEX, VIX и изменения ключевой ставки с восстановленными публикациями. Источники с неизвестным временем остаются доступными с момента загрузки. В режиме `assumed` используются 16 рядов, включая дополнительные ставки, ликвидность, Brent и курсы с лагами из конфигурации.

Панель меньше, чем в оригинальной статье, и содержит дневные финансовые индикаторы. Месячный мост к квартальному ВВП заменён дневной проекцией на лог-доходность USD/RUB. Добавление остальных макрорядов или GPR требует отдельной спецификации разночастотных измерений и отдельного сравнения.

Размер сбалансированного участка иногда сокращается до 120 дней из-за остановок торгов и сдвига окна. Фильтр продолжает использовать все доступные наблюдения 730-дневного окна. Выбор калибровочного участка, использованные колонки и доля объяснённой дисперсии сохранены для каждой даты. Во всех окнах VAR оказался устойчивым без численного ограничения: максимальный исходный спектральный радиус около 0,426 в `strict` и 0,520 в `assumed`.

Различие двух режимов не доказывает пользу точного знания публикаций: отличаются доступный состав панели и допущения. Сохранённая доступность биржевых закрытий также содержит консервативный лаг, а текущие версии ряда не заменяют архив первоначальных винтажей. Полноценная историческая point-in-time реконструкция всех источников не заявляется.

```sh
uv run usd-rub factor-backtest --start 2015-01-01 --end 2026-11-18 --test-start 2017-01-01 --window 730 --min-train 730 --mode both --output data/reports/giannone_20261118
uv run pytest -q
uv run ruff check src tests
uv run ruff format --check src tests
```

Проверки: 127 тестов проходят. Новый набор проверяет Калман/RTS независимым расчётом совместного нормального распределения, пропуски и остановки торгов, вырожденные ковариации, влияние новой публикации на состояние при неизменных PCA-параметрах, ковариации суммарной доходности и неизменность прошлых прогнозов при изменении будущих данных.
