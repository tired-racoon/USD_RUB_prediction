## Дневные прогоны ARIMA и MLP

ARIMA обучалась на логарифме дневного курса, MLP — на 12 дневных лог-доходностях. Для MLP обучена отдельная сеть на накопленное изменение каждого горизонта от 1 до 7 дней. Скрытый слой состоит из восьми нейронов с tanh. Окно обучения — 1 460 календарных дней перед 01.01.2025. Параметры фиксировались на весь тест. На дату выпуска ARIMA обновляет своё состояние по уже известному курсу, MLP получает последние известные доходности. Дневные версии используют календарь фиксинга ЦБ. Размер окна и параметры MLP зафиксированы для этого прогона. У дневной ARIMA(2, 1, 7) стандартная оценка без фильтра выбросов из месячной статьи.

```bash
uv run --locked --extra ml --extra research python scripts/paper_baselines_holdout.py
```

Скрипт сохраняет прогнозы, фактические значения и курс на дату выпуска в `data/reports/paper_baselines_holdout/predictions.csv`. [Код прогона](../scripts/paper_baselines_holdout.py)
