# Эталонные модели

Момент прогноза — 00:00 мск даты `origin`. В информационном множестве находится действующий официальный курс S[t] и предыдущие значения. Горизонт — h календарных дней. Прогноз строится для S[t+h]. Это консервативная постановка относительно времени объявления следующего курса; она отличается от nowcast перед дневным фиксингом.

Ряд ЦБ содержит даты установления новых значений. Для календарного ряда последнее действующее значение переносится вперёд до следующей записи. Обратного заполнения нет; ряд не продолжается после последней известной даты. Выходные сохраняются, поскольку официальный курс в них действует. Сама XML-выгрузка — текущая история; оригинальные винтажи исправлений курса не восстановлены.

## Формулы

| Модель | Прогноз |
|---|---|
| `rw` | S[t+h] = S[t] |
| `rw_drift` | S[t+h] = S[t] + h · среднее(ΔS) по обучающему окну |
| `ar1` | S[t+1] = c + φS[t], затем рекурсивный прогноз |
| `log_ar1` | AR(1) для log S; возврат к уровню с поправкой exp(m + v/2) |
| `returns_ar1` | AR(1) для Δlog S; прогнозы доходностей суммируются и переводятся в уровни |
| `seasonal_naive_7` | Последняя доступная календарная неделя повторяется |
| `historical_mean` | Среднее S по обучающему окну |

AR(1) оценивается OLS с константой. Коэффициент φ не обрезается принудительно до стационарной области. Постоянный ряд обрабатывается отдельно. Взрывной/неконечный прогноз вызывает ошибку. Линейные модели не ограничивают прогноз и нижнюю границу интервала нулём; неположительные прогнозы отдельно отмечаются в метриках и исключаются из логарифмических метрик.

Интервалы по умолчанию 95%, при нормальных инновациях. У RW дисперсия ошибки равна hσ². У RW с дрейфом — hσ²(1+h/n), где n — число разностей в обучении. У AR(1) уровней — σ² Σ φ^(2j). Для AR(1) доходностей используется дисперсия суммы будущих доходностей с их ковариациями, а не сумма одношаговых дисперсий. Неопределённость параметров AR и смена режима дополнительно не моделируются; покрытие интервалов нужно проверять по результатам.

Сезонный наивный прогноз на горизонте 7 совпадает с RW: его прогноз — последнее значение ряда. Это ожидаемое свойство, не независимое подтверждение модели.

Базовые методы приведены в [Forecasting: Principles and Practice](https://otexts.com/fpp3/toolbox.html), авторегрессия — в [главе AR](https://otexts.com/fpp3/AR.html). Использованы стандартные формулы, без автоматического подбора по тестовой выборке.

## Валидация

На каждой дате окно заканчивается в `origin`, параметры оцениваются заново. По умолчанию окно расширяется; `--window 730` включает скользящие два календарных года. `--min-train` задаёт минимальную длину обучения. `--step` — расстояние между моментами прогнозов, `--test-start` — первый момент прогноза. Для всех моделей и горизонтов используется одна общая выборка, заканчивающаяся за максимальный горизонт до последнего наблюдения.

Отложенная выборка не используется для выбора порядка или гиперпараметров. Проверка отдельным тестом меняет будущие значения и подтверждает неизменность ранних прогнозов.

Метрики: MAE/RMSE уровня в рублях, MAE/RMSE лог-доходности, MASE с масштабом из текущего обучающего окна, доля верных направлений, покрытие и ширина интервала. MAE/RMSE и направление также считаются по наблюдениям с фактическим изменением курса. Нулевой прогноз изменения RW считается отдельным направлением и не получает половину балла за угаданный знак.

Процентные ошибки считаются по уровню курса, отдельно для каждой модели и горизонта. Обозначим фактический курс как S, прогноз как F:

| Столбец отчёта | Формула | Смысл |
|---|---|---|
| `mape_pct` | 100 × mean(\|F − S\| / S) | Средняя абсолютная ошибка в процентах от фактического курса |
| `smape_pct` | 200 × mean(\|F − S\| / (\|S\| + \|F\|)) | Симметричная ошибка; здесь используется шкала 0–200% |
| `rmspe_pct` | 100 × sqrt(mean(((F − S) / S)²)) | Квадратичная процентная ошибка, сильнее реагирующая на большие промахи |
| `mape_changed_pct` | MAPE только при S[t+h] ≠ S[t] | Ошибка на случаях с изменившимся курсом; число случаев — `n_changed` |

Значение `mape_pct=0.5` означает 0,5%, а не долю 0,5. Для положительного курса MAPE определена; нулевые/отрицательные фактические значения вызывают ошибку. Неположительные прогнозы остаются в процентных метриках и не скрываются при подсчёте средней ошибки. Это ошибки уровня курса, а не процентная ошибка его изменения: деления на нулевое изменение в выходной нет.

Процентные столбцы сохраняются и в `metrics.csv`, и в `regime_metrics.csv`. Все календарные дни входят в основные метрики; отдельная `mape_changed_pct` показывает, насколько результат отличается без случаев с неизменным курсом. Повторный запуск с процентными метриками — [baselines_percent_20261118.md](baselines_percent_20261118.md).

`rmse_skill_vs_rw = 1 − RMSE(model)/RMSE(RW)`: положительное значение означает выигрыш. Тест Diebold–Mariano использует разность квадратичных потерь и оценку HAC с лагом перекрытия горизонтов. Его двусторонний p-value — ориентир: поправки на множественные сравнения и выбор модели после просмотра результатов нет. Для слишком короткой выборки и нулевой дисперсии разности возвращается пустое значение.

Режимы разделяются по моменту прогноза: до 24.02.2022, с 24.02.2022 по 12.06.2024, с 13.06.2024. Горизонт может пересечь границу; его относят к режиму, известному в `origin`.

ARIMAX, VAR/VECM и ML в этот набор не включены: для их честного сравнения сначала нужны согласованные исторические публикации экзогенных рядов. Добавление текущих пересмотренных макроданных как будто они были известны в прошлом исказило бы результат.
