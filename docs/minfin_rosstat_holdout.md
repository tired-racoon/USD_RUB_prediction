# Минфин и Росстат в датасете USD/RUB

[Общий снимок](../datasets/usd_rub_2011_2026_full.csv.gz) сохраняет 5 481 дату, цели и разбиение прежнего эксперимента. Он объединяет новостные признаки и признаки из обзора статей. Из `data/minfin_rosstat.csv` пришли три месячных ряда за январь 2011 — октябрь 2026. Последнее непустое значение ИПЦ в файле относится к сентябрю 2026.

На общих месяцах значения совпадают с сохранёнными рядами Минфина и Росстата. Новый файл заполнил 1 196 дополнительных дневных дат уровня ИПЦ и 1 068 дат уровня нефтегазовых доходов. Ненефтегазовые доходы добавлены в трёх колонках с месячным уровнем и изменениями за 30 и 90 дней. Накопленные с начала года доходы переведены в месячные суммы. В январе месячная сумма равна накопленной.

В CSV есть месяц наблюдения, но отсутствует календарь публикаций и винтажей. В расширенной панели используются прежние допущения о доступности в 00:00 МСК. Доходы доступны через 65 дней от начала отчётного месяца, ИПЦ — через 55 дней. Лимит возраста оставляет интервалы без текущего значения между отдельными выпусками. ИПЦ за сентябрь 2026 и бюджетные доходы за сентябрь входят в последние даты эксперимента. Октябрьские доходы при заданном лаге становятся доступны в декабре. ## Сравнение моделей

Оба прогона используют одинаковые новостные, рыночные и прочие признаки, те же 39 конфигураций и порог заполненности 50% на обучении. Валидация проводится отдельно по 2021–2024 годам. Holdout включает 680 дат прогноза с 01.01.2025 по 11.11.2026 и горизонты от одного до семи календарных дней.

| Модель | RMSE к случайному блужданию, контроль | RMSE к случайному блужданию, с CSV |
| --- | ---: | ---: |
| Ансамбль, выбранный на валидации | 91,96% | 91,96% |
| HistGradientBoosting, панель с известной доступностью | 92,44% | 92,44% |
| HistGradientBoosting, расширенная панель | 92,53% | 92,71% |
| HistGradientBoosting, рыночная панель | 93,08% | 93,08% |
| CatBoost, рыночная панель | 93,90% | 93,90% |
| Ridge, компактная панель | 93,92% | 93,92% |
| Extra Trees, рыночная панель | 94,87% | 94,87% |
| CatBoost, расширенная панель без новостей | 95,08% | 94,97% |

RMSE делится на RMSE случайного блуждания отдельно для каждого горизонта, затем берётся среднее. RMSE выбранного ансамбля составил 0,480 ₽ на день и 1,678 ₽ на семь дней. В обоих прогонах его вес распределился между компактным Ridge (43,8%), рыночным HistGradientBoosting (38,4%) и рыночным Extra Trees (17,7%).

## Вклад файла при фиксированных настройках

Для каждой из четырёх моделей взята лучшая по контрольной валидации конфигурация на расширенной панели. В двух вариантах сохранены её окно, гиперпараметры и коэффициент усадки. Все четыре переобученные модели использовали три колонки ненефтегазовых доходов. Положительное изменение означает снижение ошибки. Интервалы получены парным блочным бутстрэпом по 28-дневным блокам, по 1 000 повторов для каждой модели.

| Модель | RMSE к случайному блужданию, контроль | С CSV | Снижение, п.п. | Интервал 95%, п.п. |
| --- | ---: | ---: | ---: | ---: |
| Extra Trees | 96,04% | 95,56% | +0,48 | +0,07…+0,85 |
| HistGradientBoosting | 92,53% | 92,71% | −0,18 | −0,80…+0,74 |
| CatBoost | 95,07% | 95,33% | −0,26 | −0,53…+0,09 |
| Ridge | 98,45% | 98,91% | −0,46 | −1,03…+0,11 |

Расширенный Extra Trees выиграл от файла на этом тесте. Минимальная тестовая ошибка среди выбранных конфигураций осталась у ансамбля.

## Воспроизведение

```bash
uv run --extra ml python scripts/merge_minfin_rosstat.py \
  --snapshot datasets/usd_rub_2011_2026_news.csv.gz \
  --snapshot datasets/usd_rub_2011_2026_papers.csv.gz \
  --control data/reports/ml_holdout_minfin_rosstat/control_dataset.csv.gz \
  --output datasets/usd_rub_2011_2026_full.csv.gz

uv run --extra ml python -m usd_rub.ml_experiment \
  --dataset data/reports/ml_holdout_minfin_rosstat/control_dataset.csv.gz \
  --output data/reports/ml_holdout_minfin_rosstat/control

uv run --extra ml python -m usd_rub.ml_experiment \
  --dataset datasets/usd_rub_2011_2026_full.csv.gz \
  --output data/reports/ml_holdout_minfin_rosstat/with_file
```
