# Новостной фон для USD/RUB

Основная панель построена на заголовках «Интерфакса» и федеральной ленты МК с 01.10.2016 по 18.11.2026 включительно. Для МК берутся рубрики политики и экономики. У «Интерфакса» берётся деловая лента, а в общих лентах отбираются заголовки о политике, геополитическом риске, экономике и рынках по словарю в сборщике. Для каждого заголовка сохранены дата публикации, ссылка, архивная страница и её SHA-256. [Архив «Интерфакса»](https://www.interfax.ru/news/2022/02/24/), [архив МК](https://www.mk.ru/news/2022/02/24/)

Смартлаб добавлен из снимка RussianFinancialNews. В строках Смартлаба заголовки лежат в поле `body`. Из официального Telegram-канала РБК берётся первая строка поста длиной до 240 символов. Она проходит тематический фильтр по ключевым словам. У этих двух источников свои ряды и более короткое покрытие. [RussianFinancialNews](https://huggingface.co/datasets/Kasymkhan/RussianFinancialNews/tree/f83da5c05c82c9086806cf90ded4155052f9605c), [канал РБК](https://t.me/s/rbc_news)

В пяти днях архива «Интерфакса» фильтр не нашёл подходящих заголовков. Эмбеддинг общей панели и её тональность за эти дни пустые.

## Что в датасете

- `news__press_embedding_000`–`news__press_embedding_311` — дневной эмбеддинг. RuBERT-tiny2 кодирует каждый заголовок в единичный вектор. Средние по изданиям получают равные веса.
- `positive_share`, `negative_share`, `neutral_share` — доли заголовков по классу с наибольшей вероятностью. `positive_negative_ratio` — отношение первых двух долей. Если отрицательная доля равна нулю, отношение пустое.
- `p_positive`, `p_negative`, `p_neutral` — средние вероятности. `sentiment_balance` равен `p_positive - p_negative`, `positive_negative_prob_ratio` — `p_positive / p_negative`. Есть среднее за семь завершённых суток и отдельные оценки по экономике и политике.
- Дубли заголовков внутри издания убираются за сутки. Если один нормализованный заголовок есть в нескольких изданиях, его вес внутри каждого делится на число изданий. Перефразированные копии могут сохраниться.

Строка с датой `t` использует публикации за предыдущие календарные сутки по Москве и доступна прогнозу на `t` в 00:00 МСК. Дни без данных оставлены пустыми. Архивы выгружены ретроспективно и могут отражать правки, сделанные после публикации. Тональность описывает содержание заголовка без привязки к ожидаемому движению USD/RUB. Модели запускаются локально. [Модель эмбеддингов](https://huggingface.co/cointegrated/rubert-tiny2), [модель тональности](https://huggingface.co/seara/rubert-tiny2-russian-sentiment)

На 532 вручную размеченных финансовых заголовках FiNeS корреляция Спирмена между `p_positive - p_negative` и оценкой аннотаторов составила 0,57. При отнесении оценок от −0,2 до +0,2 к нейтральному классу macro-F1 у жёстких классов модели составил 0,20, у самого частого класса — 0,21. Модель отнесла к нейтральным около 89% заголовков. Доли по жёстким классам стоит читать как оценки модели с этим смещением. [FiNeS](https://github.com/WebOfRussia/financial-news-sentiment)

## Воспроизведение

```bash
uv sync --extra news
uv run usd-rub news-fetch --start 2016-10-01 --end 2026-11-18
uv run --extra news hf download Kasymkhan/RussianFinancialNews --repo-type dataset \
  --revision f83da5c05c82c9086806cf90ded4155052f9605c \
  'data/train-00000-of-00001.parquet' 'data/test-00000-of-00001.parquet' \
  --local-dir data/news/inputs/russian-financial-news
uv run --extra news usd-rub news-features --rbc-ids 148000:161000 \
  --smartlab-parquet data/news/inputs/russian-financial-news/data/train-00000-of-00001.parquet \
  --smartlab-parquet data/news/inputs/russian-financial-news/data/test-00000-of-00001.parquet
uv run python scripts/export_ml_dataset.py \
  --input datasets/usd_rub_2011_2026.csv.gz \
  --news-features data/news/daily.csv.gz \
  --news-features data/news/daily_smartlab.csv.gz \
  --news-features data/news/daily_rbc.csv.gz \
  --min-hit-rate 0 \
  --output datasets/usd_rub_2011_2026_news.csv.gz
```

Команда экспорта соединяет признаки с базовым датасетом по дате прогноза. Порог заполненности `0` сохраняет ряды Смартлаба и РБК в исследовательском снимке. При стандартном пороге 50% они не проходят отбор по обучающему интервалу. В `data/news` также лежат корпус, оценки отдельных заголовков, покрытие архивов и параметры расчёта.
