# События из новостей и прогноз USD/RUB

Qwen3.5 Flash через VseLLM размечает заголовки «Интерфакса» и МК из [новостного корпуса](news_features.md). Словарь ограничивает вход до 24 заголовков на день, отсекает повторы, комментарии и сообщения о движении самого курса. Из текста выделяются события по пяти каналам — платежи и санкции, экспорт сырья, ставки и инфляция, валютные меры, геополитика. Отдельно записывается стадия события и идентификаторы подтверждающих заголовков. Для ответов с нарушением формата используется повтор с более явным примером JSON. [VseLLM API](https://vsellm.ru/docs)

Число событий считается по каналу и стадии за 1, 3 и 7 завершённых суток. Первый доступный срез — в 00:00 МСК следующего дня. Словарный контроль строится по тем же заголовкам. Пропуск в разметке оставляет дату без новостной поправки во всех сравниваемых вариантах.

## Эксперимент

Сравниваются три варианта поправки к [прежнему ансамблю](minfin_rosstat_holdout.md). Признаки берутся из словарной разметки, из LLM или из обеих. Поправка учится на ошибках вневыборочных прогнозов ансамбля. Для каждого года с 2017 по 2024 компоненты ансамбля обучены на данных до начала года с настройками, зафиксированными в прежнем эксперименте. Для поправки проверены 12 конфигураций Ridge и HistGradientBoosting. Гиперпараметры и коэффициент поправки от 0 до 1 выбирались на фолдах 2021–2024. Тест включает те же 680 дат с 01.01.2025 по 11.11.2026.

Размечены все 3 701 сутки с 01.10.2016 по 18.11.2026. В 3 517 днях словарь нашёл заголовки для запроса. В обработку вошли 26 405 заголовков, из которых модель извлекла 3 564 записи о событиях. [Готовый снимок из 120 признаков](../datasets/llm_news_event_features_2016_2026.csv.gz). Расчётная стоимость по возвращённым токенам — 13,29 ₽. [Тарифы VseLLM](https://vsellm.ru/provider/VSELLM)

## Результаты

Во всех трёх вариантах валидация выбрала нулевой коэффициент поправки. На тесте остался прежний прогноз ансамбля. RMSE составил 0,480 ₽ на день и 1,678 ₽ на семь дней. В таблице RMSE нормирован на случайное блуждание по каждому горизонту и усреднён.

| Признаки поправки | Вес по валидации | RMSE к случайному блужданию | RMSE при весе 1 |
| --- | ---: | ---: | ---: |
| Словарные события | 0 | 91,96% | 93,74% |
| LLM-события | 0 | 91,96% | 92,44% |
| Словарь и LLM | 0 | 91,96% | 94,17% |

Архивный тест проверяет гипотезу о полезности признаков. Современная LLM могла видеть события из этого интервала при обучении. Для проверки на будущих датах нужно зафиксировать промпт, способ отбора заголовков и конфигурацию поправки до начала наблюдений. [Исследование запоминания финансовых данных в LLM](https://arxiv.org/abs/2504.14765)

## Воспроизведение

```bash
uv run --extra ml python scripts/llm_news_holdout.py \
  --features datasets/llm_news_event_features_2016_2026.csv.gz
```

Пересборка признаков из архивных заголовков выполняется через VseLLM.

```bash
uv run python scripts/label_llm_news.py
uv run --extra ml python scripts/llm_news_holdout.py
```

`label_llm_news.py` читает `VSELLM_API_KEY` из окружения или локального файла `.env`. Разметка сохраняется в `data/reports/llm_news_holdout/days`. Повторный запуск использует ранее проверенные ответы. Стоимость оценивается по токенам, полученным от API. Признаки, прогнозы и метрики сохраняются в `data/reports/llm_news_holdout`.
