# Результаты сбора действующих источников

Проверено 18 ноября 2026 года. В этой итерации выполнены реальные загрузки из 26 дополнительных табличных источников/конфигураций, дополнены официальные текстовые архивы и санкционные списки. Все перечисленные загрузки бесплатны и не требуют пользовательских токенов.

Актуальность проверяется по наблюдениям 2026 года; для санкционных снимков — по дате выпуска файла. GDELT исключён по требованию пользователя. Его старые пробные файлы, устаревшие VKO/Saldo и непроверенные Zenodo не используются при обучении и сборке признаков.

Квартальные даты — конец квартала; месячные даты обычно первое число отчётного месяца, а не день публикации. Точные единицы, источник и контрольная сумма записаны в каждом CSV. Для Si цены переведены из RUB за 1000 USD в RUB/USD. Для бюджета баланс сохраняет знак Минфина: дефицит отрицательный, профицит положительный. Месячные суммы получаются разностью накопленных внутри одного года; пропуски не перескакиваются.

У старой отключённой серии `cbr_fx_net_purchases` исправлена ошибочная подпись единицы: млн USD, а не млрд RUB. Она остаётся исключённой и не подменяет операции Минфина.

## Новости и официальные документы

- **OFAC Recent Actions: 1913 уникальных документов**, 02.01.2015–13.11.2026, тексты скачаны без ошибок. Это все темы выбранного архива, не только Россия. Дубликаты ссылок между страницами объединены. Индекс: `data/documents/ofac_2015_2026.json`; отдельные тексты: `data/documents/ofac_archive/`.
- **ЦБ: 112 материалов ДКП**, 30.01.2015–23.10.2026. Индекс и тексты: `data/documents/cbr_decisions/`. Время, указанное архивом, сохраняется отдельно. Это не все новости ЦБ за период.
- **ORFR: 78 PDF**, январь 2017 — октябрь 2026. Сохранены страницы текста и ссылки. Совмещённые выпуски с неоднозначным месяцем не превращаются в месячные наблюдения. Прежнее определение «крупнейшие экспортёры» не объединяется с «нефинансовые компании».
- **Минэкономразвития: 30 публикаций Urals**, сохранены целиком вместе с числовыми ценами.
- **NBS: 12 публикаций PMI**, содержат исторические таблицы с перекрытиями. Это архив текущих версий страниц, не доказательство первоначального текста публикации.
- **UK: 263 записи журнала изменений** прежней Russia sanctions publication, до 27.01.2026. Он не покрывает последующие изменения FCDO; актуальный снимок UKSL хранится отдельно.

Готовый общий корпус экономических/политических новостей и санкционный sentiment не построены. Страницы government.ru/Kremlin получены для проверки доступа; они не считаются полной историей нормативных изменений.

## Проверка допуска и оставшиеся пробелы

`audit` проверил 296 сохранённых числовых рядов:

- 107 имеют временной размах не меньше десяти лет, представлены все календарные годы, есть наблюдения за 2026 год;
- 3 ряда ФНС имеют такой размах, но отсутствует 2017 год;
- 146 рядов имеют более короткую историю, включая 110 товарных индексов Росстата;
- 40 старых или исключённых рядов не допускаются к использованию.

Это количество колонок, а не независимых факторов: например, исходные/SA, месячные/YTD и отдельные товарные индексы считаются отдельно. Проверка наличия всех лет не доказывает отсутствие пропущенных дней/месяцев; отчёт содержит максимальные разрывы и число дат. Короткие и неполные источники не проходят строгий `--require-10y`.

Весь список из MD ещё не спарсен. Подробный перечень неполученного и причин — в [sources.md](sources.md). Среди пробелов: розничный оборот (404), текущий OTC, полный месячный Urals до 2024, непрерывные продажи экспортёров/спрос населения, общий недельный ИПЦ, ликвидная часть ФНБ, CNH, опционные поверхности, CNY swap curve, промпроизводство Китая, сырьевые физические потоки, полный реестр правовых изменений и история settlement/аукционов/купонов. Платные и ненаблюдаемые величины не добавляются под похожими названиями.

## Воспроизведение и проверки

```sh
uv sync --python 3.12
uv run usd-rub fetch --sources moex_si_front,cbr_bop,cbr_business,minfin_fnb,minfin_budget,nbs_pmi,worldbank_commodities --start 2015-01-01 --end 2026-11-18 --browser-fallback
uv run usd-rub fetch --sources cbr_expectations,cbr_cny_funding,cbr_settlements,minfin_fx_budget,cbr_orfr,economy_urals,rosstat_industry,rosstat_weekly_items,fns_calendar --start 2015-01-01 --end 2026-11-18 --browser-fallback
uv run usd-rub fetch --sources moex_usdrubf,moex_cnyrubf,cbr_correspondent_accounts,cbr_bank_deposits,cbr_deposit_rate,cbr_repo_claims,fred_usd_brl,fred_usd_mxn,fred_usd_zar,fred_usd_inr --start 2015-01-01 --end 2026-11-18
uv run usd-rub ofac --start 2015-01-01 --end 2026-11-18 --documents --output data/documents/ofac_2015_2026.json
uv run usd-rub cbr-releases --start 2015-01-01 --end 2026-11-18
uv run usd-rub sanctions
uv run usd-rub audit
uv run pytest -q
uv run ruff check src tests
uv run ruff format --check src tests
```

Проверки: **79 тестов проходят**, `ruff check` и `ruff format --check` проходят. Новые тесты проверяют разделение наблюдения и публикации, различие горизонтов ожиданий, квартальные даты, сноски, единицы, накопленные суммы, выбор контракта по году экспирации, границу роллирования, повторяющиеся страницы OFAC, даты санкционных снимков, число сущностей OFAC, кодировки/версии ФНС, отсутствующие годы и блокировку исключённых источников.

Машинные результаты: [additional_downloads_2026.json](additional_downloads_2026.json) — отчёты 26 загрузчиков; [active_sources_2026.json](active_sources_2026.json) — каждый ряд с датами, разрывами и источниками. Сырые файлы и таблицы находятся в `data/` и исключены из Git.

Для пересматриваемых таблиц без доказанной исторической даты публикации `available_at` остаётся датой загрузки. Эти данные не становятся автоматически честным историческим point-in-time датасетом. Модели RW/AR(1) не менялись; результаты их сравнения находятся в [validation.md](validation.md).
