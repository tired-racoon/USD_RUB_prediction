# USD/RUB на 1–7 дней по внутридневным данным

Прогнал 200 конфигураций на 680 общих датах с 01.01.2025 по 11.11.2026. Наименьший средний RMSE к случайному блужданию — **86,84%** против **89,07%** у основного ансамбля. Смесь, выбранная по фолдам 2022–2024 годов, дала **87,15%**. У обеих смесей основной выигрыш на горизонтах 1–3 дня. [Таблица всех запусков](fx_candles_experiments.csv)

На 1–7 дней считается RMSE в рублях. Итоговый скор — среднее семи отношений к RMSE случайного блуждания на тех же датах. Валидационный скор усреднён по трём годовым фолдам с равными весами.

Выбранная по валидации смесь снизила тестовую ошибку на 1,92 п.п. Парный 95%-й интервал по 28-дневным блокам — от +1,13 до +2,54 п.п. В 2025 году скор снизился с 88,12% до 86,00%, в 2026-м — с 90,37% до 88,79%. У варианта с весом 100% выигрыш составил 2,23 п.п. Его вес выбран по минимуму на тесте. Бутстрэп учитывает зависимость соседних дат. Интервал рассчитан для конкретной смеси после отбора конфигураций.

## Данные

Из ISS скачано 75 356 часовых свечей. Торговая сессия попадает в признаки со следующих суток по Москве. Для каждой свечи взял время окончания и добавил 15 минут в качестве лага доступа. Это исключает полную свечу 23:00–23:59 со среза 00:00 МСК. Взял цены до 13:00, 16:00 и 19:00, последнюю доступную цену и доходности между ними. Для фьючерсов посчитал долю вечернего объёма и объём со знаком изменения цены внутри свечи. Для пропущенных торговых дней сессия переносится максимум до четвёртых суток после даты торгов. Переход на внебиржевые котировки USD и EUR в июне 2024 года меняет смысл биржевых спредов. С 27 декабря 2024 года ЦБ объединяет данные биржевого и внебиржевого сегментов. Исторические фолды охватывают разные режимы, а отдельный срез с 13.06.2024 до конца валидации содержит 195 дат. На нём выиграла смесь на XGBoost с долей 50%. ## Как устроены эксперименты

- **92 модели.** Ridge, регрессия Хьюбера и XGBoost, с отдельным обучением на каждом горизонте или с общими коэффициентами по числу предстоящих фиксингов. Сравнил прямую доходность к текущему курсу и поправку к базовому ансамблю с t0-gamma. Проверил годовое и месячное переобучение, окна в 365 и 730 дней, затухание весов и пониженный вес наблюдений до смены режима. В качестве контроля дал тем же моделям дневные котировки. Идею проверить несколько скоростей адаптации взял из работы Inoue, Jin и Rossi. [Статья](https://doi.org/10.1016/j.jeconom.2016.03.006)
- **108 смесей.** Шесть групп рыночных моделей, три границы по числу новых фиксингов, три постоянные и три пересчитываемые доли. Когда на несколько календарных дат приходится один фиксинг, прогноз курса у них совпадает. Доли на пересчитываемых смесях обучаются на уже известных ошибках предыдущих прогнозов.
- **Лучшая группа на спредах.** Среднее трёх моделей. Две Ridge прогнозируют доходность к текущему курсу, третья оценивает поправку к ансамблю с t0-gamma и использует общие коэффициенты по горизонту. Девять входов включают спред CNY/RUB, центрированный спред USDRUBF, вечернее движение CNY/RUB и бессрочных фьючерсов, кросс фьючерсов, спред биржевого USD/RUB до июня 2024 года, последнее изменение и волатильность курса. В итоговой смеси прогноз этой группы получает 50% веса на первых трёх **новых фиксингах** с даты прогноза. При выходных третий фиксинг может приходиться на пятый календарный день.

Обучение идёт по мере поступления фактов. В каждый момент переобучения включены только строки, для которых цель на семь дней уже известна. Поэтому модели с месячным или годовым обновлением могут использовать завершённые наблюдения из ранней части периода 2025–2026. Веса фиксированных смесей применяются одинаково в каждом фолде и на тесте. Состав группы на спредах уточнил после первого просмотра результатов 2025–2026. Вся оценка относится к повторно использованному историческому тесту.

Смесь с кроссом НБРБ и половинной долей на первом фиксинге дала 88,08% на тесте. Добавление этого же кросса к прямой Ridge подняло ошибку с 87,25% до 88,14%. Лучший XGBoost первого этапа по общей валидации дал 93,36% на тесте.

## Воспроизведение

Нужны [архив базовых прогнозов](forecast_stacking.md) и [панель макропризнаков](theory_holdout.md), которые уже используются основным бэктестом. В локальном `data/normalized` используются 11 рядов с сохранённой доступностью. Команды скачивают рыночные данные, обучают модели и считают итоговые смеси.

```bash
uv run --locked python scripts/download_fx_candles.py
uv run --locked python scripts/download_nbrb_cross.py
uv run --locked --extra ml python scripts/fx_candles_holdout.py
uv run --locked --extra ml python scripts/fx_candles_blends.py
```

В `data/reports/fx_candles_holdout/` и `data/reports/fx_candles_blends/` сохранены `summary.csv`, `by_year.csv`, `predictions.csv.gz` и `run.json` с конфигурациями, хешами входов и парными интервалами. Строки прогноза идентифицируются по `origin` и `horizon`.
