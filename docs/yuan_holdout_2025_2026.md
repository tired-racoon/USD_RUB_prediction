# Прогноз USD/RUB через юань на 1–7 дней

Раздельный прогноз двух юаневых пар и базиса снизил среднее отношение RMSE к случайному блужданию на 6,66%. Прямой Ridge на той же панели снизил его на 7,02%, прежний ансамбль — на 7,63%. При добавлении RUSFAR CNY выигрыш раздельной модели сократился до 6,05%, хотя средний MAPE немного улучшился.

На семи днях простой кросс по закрытию MOEX дал 1,646 ₽ против 1,679 ₽ у прежнего ансамбля. Разница RMSE составила −0,033 ₽, а 95%-й интервал по парному блочному бутстрэпу — от −0,115 до +0,054 ₽. На одном дне кросс по закрытию заметно проиграл. Эту котировку имеет смысл оставить как отдельный ориентир для сравнения по горизонтам.

Парный блочный бутстрэп по датам (1 000 повторов, блок 28 дней) дал 95%-й интервал среднего выигрыша к RW от 3,21% до 9,51%. У кросса по закрытию соответствующий интервал от −6,72% до +7,76%. ## Данные к моменту прогноза

- Цель и время среза совпадают с прежним экспериментом. В 00:00 МСК действующий официальный USD/RUB известен. На нерабочих днях сохраняется действующий курс. Цели — официальные значения через 1–7 календарных дней. Архивные прогнозы взяты из запуска с порогом заполненности 50%. Перед сравнением проверено совпадение даты цели, действующего и будущего курсов. [Прежний эксперимент](ml_holdout_2025_2026.md)
- Российская нога — CNYRUB_TOM MOEX в рублях за юань. В моделях используется VWAP, для сравнения рассчитан кросс с закрытием. Сохранённые дневные агрегаты в проекте доступны со следующей полуночи МСК. [Валютный рынок MOEX](https://www.moex.com/ru/markets/currency)
- Внешняя нога в юанях за доллар — курсы ЕЦБ `EUR/CNY ÷ EUR/USD` одной даты. ЕЦБ публикует дневные справочные курсы около 16:00 по центральноевропейскому времени. Модель видит их со следующей полуночи МСК. Ряд H.10 из прежнего эксперимента публикует дневные наблюдения за неделю одним выпуском. [ЕЦБ](https://data.ecb.europa.eu/methodology/exchange-rates), [график H.10](https://www.federalreserve.gov/Releases/H10/)
- Ноги подбираются независимо по времени доступности. На тесте у них одинаковая дата наблюдения на 646 из 680 срезов. Возраст самой старой использованной котировки MOEX — 6 дней, ЕЦБ — 5. Даже в один день VWAP и фиксинг ЕЦБ отражают разные часы. Базис включает это расхождение, а также расхождение между отдельными сегментами рынка и официальным курсом. Использованы сохранённые винтажи MOEX и текущий исторический архив ЕЦБ.

## Как устроен прогноз

Текущий кросс `X = CNY/RUB × USD/CNY`. Мультипликативный базис `B = USD/RUB ЦБ ÷ X`. Для каждого горизонта Ridge прогнозирует относительное изменение CNY/RUB, USD/CNY и базиса. Произведение трёх прогнозных уровней даёт прогноз официального USD/RUB. Поправка к действующему курсу усаживается коэффициентом, выбранным до 2025 года.

Российская нога использует историю CNY/RUB, USD/RUB, базиса и календарь. Внешняя нога использует историю USD/CNY, календарь и возраст котировки. Модель базиса и контрольный прямой Ridge используют общую панель. В варианте с фондированием к российской ноге и базису добавлены RUSFAR CNY, его отклонение от 21-дневной медианы и возраст значения. Столбец участвует в обучении с момента, когда в окне накопилось хотя бы 60 наблюдений.

История для расчёта признаков начинается в январе 2017 года. Ridge обучается на окне до 1 460 дней отдельно для каждого горизонта. Хронологические фолды — 2021, 2022, 2023 и 2024 годы. Целевая дата обучающего примера должна наступить до начала следующего периода. Даты прогноза внутри фолда имеют все семь наблюдаемых целей в том же году. После 31.12.2024 параметры заморожены. Интервалы из квантилей ошибок валидации на тесте дали около 99% покрытия против номинальных 95%, то есть оказались широкими для этой выборки.

## Воспроизведение

```bash
uv run --extra ml python -m usd_rub.yuan_experiment \
  --output data/reports/yuan_holdout_ecb_rerun \
  --old-predictions data/reports/ml_holdout_50pct/predictions.csv
```

В `data/reports/yuan_holdout_ecb_2025_2026/` лежат прогнозы, метрики по горизонтам и годам, результаты валидации и входные котировки с датами доступности. `run.json` содержит хэши входов и архива ЕЦБ. Для нового запуска нужен новый каталог. Аргумент `--old-predictions` можно опустить, если локально нет архива предыдущего эксперимента. [Конфигурация](../config/yuan_holdout.json)
