# Исправления данных после аудита

Выполнено 18 ноября 2026 года. Исходный [аудит](data_audit_2026-11-18.md) относится к снимку до изменений. Загрузчики исправлены, доступные источники обновлены, сохранённые ответы повторно нормализованы, признаки и бейзлайны пересчитаны до 18 ноября включительно.

Raw-объекты сохранены. Копия прежних таблиц, документов, признаков и кода находится в `data/repairs/2026-11-18/before`. Повторный запуск исправлений проверен на реальных файлах: хеши нормализованных рядов и календарей не изменились. Результат — [repair_idempotence_2026-11-18.json](../data/reports/repair_idempotence_2026-11-18.json).

Текущий набор содержит 312 рядов и 275 749 строк с версиями. Для актуальности и допуска: 87 рядов имеют длинный проверенный диапазон без обнаруженных календарных/месячных пробелов, у пяти длинных рядов есть пробелы, 160 рядов имеют короткую историю, 43 исключены, 17 требуют обновления или замены текущего источника. Эти категории не подтверждают прогнозную пользу и не означают, что все ряды пригодны для исторического обучения.

Дополнительная проверка рыночных признаков повторена вместе с аудитом; её методика и ограничения находятся рядом с результатами.

## Что остаётся ограничением источников

1. **Календарь ФНС за 2017 год.** В опубликованных выпусках, которые удалось получить, этот год отсутствует. Он явно отмечен как пробел и не заполняется соседним годом или номинальными налоговыми датами.
2. **Движение ФНБ.** Равенство не сходится в 79 из 142 месяцев, максимальный остаток — 1 538,01 млрд рублей. То же обнаружено в исходной таблице. До отдельного подтверждения методологии потоки исключены. Подробности: [fnb_reconciliation.csv](../data/reports/fnb_reconciliation.csv).
3. **Исторические публикации и пересмотры.** Для части рядов по-прежнему нет подтверждённых времён и винтажей. В окружении нет `FRED_API_KEY` для ALFRED. Неизвестные данные доступны строго с момента получения; предположения о лагах разрешены только в исследовательском режиме. Датированный текущий текст NBS тоже не сертифицирует неизменность всех прошлых версий.
4. **Розничная торговля Росстата.** Повторная загрузка завершилась 404, в том числе через Chrome. Данные не созданы искусственно.
5. **Подробный платёжный баланс и продажи экспортёров.** Старые подробные ряды не объявлены текущими. Ранние оценки отделены; извлечённые фрагменты ORFR не выданы за полную месячную историю.
6. **Классификация санкций.** Метки OFAC основаны на заголовках; они не определяют величину валютного шока, число затронутых лиц или направление движения курса. Для смешанных программ нужна проверка текста. История изменений UK — история страницы списка, а не полный юридический архив.

Полное машинное описание локальных исправлений и незакрытых пунктов: [repairs_2026-11-18.json](../data/reports/repairs_2026-11-18.json).

## Проверка и повторение

`pytest`: **93 passed**. Проверены разделение месячных/YTD, отсутствие данных до публикации, эффективная дата ставки, версии и удаления налоговых событий, пропущенный год, варианты имён UK, временные границы архивов и отдельные ранние оценки платёжного баланса. `ruff check` и `ruff format --check` проходят.

Повторный полный аудит: [post_repair_audit_2026-11-18](../data/reports/post_repair_audit_2026-11-18/audit.json). Он отдельно проверяет числовое соответствие исходникам, пересборку признаков, зависимости, raw-хеши и сохранённые метрики. Несверенный баланс ФНБ в нём остаётся видимым, несмотря на исключение потоков из обучения.

```sh
uv run usd-rub repair-data --as-of 2026-11-18
uv run usd-rub features --end 2026-11-18
uv run usd-rub audit --as-of 2026-11-18
uv run python scripts/audit_data_snapshot.py \
  --as-of 2026-11-18 \
  --output data/reports/verification_2026-11-18
```

`repair-data` работает с сохранёнными ответами. Для обновления источников нужна отдельная загрузка с `--refresh`. Перед последовательными сборками следует дождаться завершения загрузок: изменение входных файлов во время сборки признаков вызывает ошибку, а полный аудит записывает такие изменения в `inputs_changed_during_run`.
